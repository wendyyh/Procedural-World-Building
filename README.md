# Procedural World Building

An interactive WebGL material study and a growing technical reference for browser-based procedural worlds.

## Run locally

```bash
npm install
npm run dev
```

The project includes an orbit camera, interactive sample geometry, multiple material models, scene lighting and shadows, a distance-fading world grid, selectable background palettes, and a wireframe topology view.

Create a production build with:

```bash
npm run build
```

Technical walkthroughs are available in [`docs/tutorial`](./docs/tutorial/README.md).
